## Submission recommendation

- Upload TIFF when the system explicitly asks for a high-resolution figure.
- Upload PNG when TIFF is not accepted or the previewer handles PNG better.
- Use PDF for repositories, LaTeX compilation, and systems that accept vector
  figures.
