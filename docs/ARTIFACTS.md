# Released Artifacts

## Pretraining Dataset

Ethosoft/nedo-turkish-65k-tokenized-60b

60.95B-token Turkish web-corpus snapshot tokenized with the NEDO Turkish 65K tokenizer.

## SFT Dataset

Ethosoft/nedo-turkish-sft-mixtures

Turkish supervised fine-tuning mixtures, including a cleaner 20K subset and a broader 104K mixture.

## Base Model

Ethosoft/nedoqwen_0.8b_base_pretrained

Custom PyTorch bf16 checkpoint for the NEDOQwen 0.8B base pretrained model.

## SFT Model

Ethosoft/nedoqwen_0.8b_pretrained_sft

Experimental Turkish instruction-tuned checkpoint based on the base pretrained model.
